# Перед публичным запуском лендинга

В футтере документы сейчас обозначены как «Готовятся» и не являются ссылками.
Это места для будущих материалов, а не опубликованные условия сервиса.

- Подготовить и опубликовать политику конфиденциальности, условия использования
  и сведения об обработке персональных данных; заменить подписи реальными ссылками.
- Добавить подтверждённый канал поддержки и сведения об операторе продукта.
- После реализации самостоятельного подключения тарифов заменить подпись
  «Подключает администратор» реальным действием и проверить весь сценарий оплаты.
- Проверить актуальность цен, кредитов и возможностей по публичному API каталога.
- Сверить демонстрационный обзор звонка с актуальным кабинетом. Пример на первом
  экране обозначен как «Пример интерфейса»; его дорожка записи декоративная.
- Решить, нужен ли завершающий блок «Меньше прослушивания. Больше ясности.».
  Он самостоятельный и может быть удалён без изменения футтера и тарифов.
- Повторить проверку лендинга в обеих темах, с отключённым WebGL, при ошибке
  загрузки модели, с уменьшенной анимацией, на телефонах и низких мониторах.

Резервный экран для проверки: `/?flat=1`. Изображение первого экрана постепенно
исчезает при прокрутке; ниже остаётся фон рабочего пространства.
